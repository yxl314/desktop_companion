# 发布校验清单（每个版本）

## 构建与测试

- [ ] `cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=C:/msys2/ucrt64`
- [ ] `ninja -C build`
- [ ] `ctest --output-on-failure`（14 套单测全过）
- [ ] `cxx_ci`：clean / configure / build / test 全 ok
- [ ] `cxx_audit`：clang-tidy 0 错误（警告记录在 reports/）

## 打包与产物

- [ ] `cxx_pkg` 成功生成 `dist/desktop_companion-<ver>-win64.zip`
- [ ] ZIP 内含 exe、Qt DLL、plugins（platforms/styles/imageformats/sqldrivers）、qml 目录
- [ ] `dist/SHA256SUMS` 存在且与 ZIP 一致（`sha256sum -c`）
- [ ] 解压到干净目录可直接启动（无 MSYS2 环境变量）

## 冒烟（VM 无 GPU 时加 `QT_QUICK_BACKEND=software`）

- [ ] `--shot <dir>`：桌宠/气泡/聊天/控制中心截图非空
- [ ] `--smoke <dir>`：发送一条消息、收到回复、截图落盘
- [ ] `--demo <dir>`：云端模型回复（需配置 Key）
- [ ] 托盘菜单、右键菜单、设置打开/关闭
- [ ] 二次启动：气泡提示「已在运行」
- [ ] 日志中无 API Key / 聊天原文

## 交付

- [ ] 部署到 Windows 桌面 `桌面桌宠-<ver>/` + zip + 使用说明
- [ ] 提交回 honor 仓库（本地无远程）
