## 主要变更

- **架构**：按 `docs/架构重构-MVVM.md` 完成经典 MVVM + 模块化：
  `src/app`（View 装配）/ `src/viewmodels`（11 VM + 基类 + DialogService）/
  `src/domain` / `src/data` / `src/services` / `src/platform`；删除旧 `src/bridge.*`（1900+ 行上帝类）。
- **UI/UX**：主窗口成为软件本体（1280×800，200px 侧栏 + 页面栈 + 状态栏），
  10 个页面（聊天/角色/人设/世界观/记忆/模型/记录/数据/设置/关于）；
  参考 real_esrguisoft / ccswitch v4 设计 token，亮暗主题、品牌青绿 #0F766E、
  22 个复用组件 + 34 个 lucide 图标；专注聊天 760px、卡片折叠、点赞点踩、推荐问句。
- **桌宠**：从主窗口启动/停止，支持 1~3 只、开机自动启动、点击穿透、贴边、悬浮球位置持久化；
  独立桌面 Chat 窗口移除，聊天统一在主窗口。
- **需求补齐**：WLD-L-01 同世界观角色互知；导入导出异步化；C++/QML 全量英文化（560 条、0 unfinished）；
  ChatStore 历史 id/feedback 修复；Doxygen 覆盖新层。
- **回归**：14/14 单测；主窗口/各页面/暗色/英文/demo 对话截图验证。
