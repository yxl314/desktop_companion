## 9. 1.1 MVVM 重构后的实现位置映射

| 层 | 目录 | 说明 |
| --- | --- | --- |
| View（QML） | qml/MainWindow.qml、qml/pages/**、qml/components/**、qml/pet/** | 只绑定 ViewModel 属性/命令，主题 token 来自 qml/theme |
| View（C++ 装配） | src/app/application.{h,cpp}、windowregistry.{h,cpp} | 服务/VM 构造、QML context property、窗口/托盘/快捷键、截图验证 |
| ViewModel | src/viewmodels/** | 11 个 VM + ViewModelBase + DialogService；Q_PROPERTY/Q_INVOKABLE/信号 |
| Model（domain） | src/domain/** | AppConfig/ModelProfile、Character/Persona/World、StoredMessage、MemoryEntry、Intimacy |
| Model（data） | src/data/** | config/chat/character/world/persona/memory/intimacy 仓库（SQLite/JSON/文件） |
| Model（services） | src/services/** | LLM/SSE/ChatService/PromptBuilder/CharacterPack/PersonaFile/Autostart/ErrorCodes/SecretStore |
| Model（platform） | src/platform/** | 全局快捷键、前台应用探测、alpha 命中、meta 命中区、窗口区域 |
| 测试 | tests/** | 14 组 ctest；14/14 通过 |

依赖规则：View → ViewModel → Model（单向向下）；QML 不直接访问服务/文件；
ViewModel 不 include QML/窗口类；旧 `src/bridge.*` 已删除，逻辑由 ViewModel 接管。
