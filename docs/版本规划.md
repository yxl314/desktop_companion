# desktop_companion 版本规划与需求追踪

依据：`方案设计.md`（777 行，需求 ID 见第二章）。
原则：小步快跑、每版可编译/可测试/可打包；每版结束跑 cxx_ci + cxx_audit + cxx_pkg，
产物放 Windows 桌面，提交 honor 仓库 main。需求验收矩阵在本文档末尾持续更新。

## 1. 现状（0.3，已完成）

已实现：托盘/单实例/日志/原子配置/DPAPI Key、桌宠显示与拖动、点击气泡、命中区比例分区、
聊天窗流式对话（OpenAI 兼容 + OpenCode Go）、预设/测试连接、人设 .md 导入与切换、
SQLite 聊天记录与恢复、开机自启、控制中心（模型/人设/关于）、sse/chatstore/config 单测。

已知缺口（对应后续版本）：前端数据模型（角色/世界观）、记忆/好感度、点击穿透、
命中区 meta、多桌宠、贴边隐藏/悬浮球、拖拽三态、全局快捷键、模式、主题、i18n、
聊天记录查看/导出、日志查看、新手引导、错误码体系、数据迁移与损坏恢复、性能验收。
